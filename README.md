## Run ECOMAN: Seismic Anisotropy in Cascadia

Scripts and parameter files used in preparation for the master's thesis:

**"Understanding seismic anisotropy observations in the context of 3D slab-induced flow in the Cascadia subduction zone"**

## Overview

This repository contains the numerical modeling scripts, configuration setups, and analysis workflows used to simulate mantle dynamics and predict seismic anisotropy within the Cascadia subduction zone.
